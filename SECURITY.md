# Security Policy

## Supported Versions

Security fixes are provided for the latest released version of the Rustatio
Home Assistant App.

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Use GitHub's private vulnerability reporting feature for this repository
instead.

When reporting a vulnerability, please include:

- A description of the issue and its potential impact
- Steps to reproduce the issue
- The affected Rustatio Home Assistant App version
- Your Home Assistant version and architecture, when relevant
- Any logs or configuration required to reproduce the issue, with secrets and
  personal information removed

Security reports will be reviewed as soon as reasonably possible.

## Scope

This repository contains the Home Assistant App wrapper for Rustatio.

Security issues in the upstream Rustatio application itself should be reported
to the upstream Rustatio project.

Issues specific to the Home Assistant packaging, Ingress proxy, container
configuration, AppArmor profile, discovery mechanism, or interaction with
Home Assistant should be reported here.
